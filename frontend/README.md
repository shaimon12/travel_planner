# AI Travel Planner Pro — Frontend Client

Modern, responsive web application for AI Travel Planner Pro.

## Technology Stack
- **Framework**: React 18 / 19 with TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS & Lucide Icons
- **Markdown Support**: `react-markdown` with GFM plugin
- **State & Networking**: Native fetch/axios communicating with the FastAPI backend

This client will be fully scaffolded and built during Phase 3 with:
- Persistent sidebar for trip history and session management
- Dual-view interface: Interactive Itinerary (with auto-scrolling chat) vs. Destination Analytics & Map
- Real-time Markdown rendering with geo-linked places
